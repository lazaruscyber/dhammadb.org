This page explains how to contribute and edit contents on this wiki.

## How contribution works

DhammaDB is purposly a closed access wiki. We have done this to prevent misinformation. Although creating content is not possible for users, we have made a expection for editing content. Users may join our Discord server and make a ticket with the **Page ID** and the contents you want to change. Please follow the specified format in the template below. All other formats will not be accepted.

:::important Template for Edit Request
`Page ID: (Located at the bottom of every page, this is *not* the page name in the page url)`\
`Section: (The section you want to edit)`\
`Draft: (The section rewritten with your changes)`
:::
